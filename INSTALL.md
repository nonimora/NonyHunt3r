# 📥 How To Install NonyHunt3r

### For Linux / Kali Linux / Ubuntu / Parrot OS

**If you see this error:** `externally-managed-environment`

**Do this:**

1. Clone the tool:
```bash
git clone https://github.com/nonimora/NonyHunt3r.git
cd NonyHunt3r
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 NonyHunt3r.py

🔥 Quick Method (If venv doesn't work)
git clone https://github.com/nonimora/NonyHunt3r.git
cd NonyHunt3r
pip3 install -r requirements.txt --break-system-packages
python3 NonyHunt3r.py

🪟 For Windows Users

git clone https://github.com/nonimora/NonyHunt3r.git
